# Turbo Riot roadmap

**Current development milestone: v0.2.0 — Race Foundations.** This patch is an unaccepted development build, not a published release.

| Milestone | Scope |
| --- | --- |
| **v0.1.0 — First Drive** | Existing baseline: arcade kart, independent input/camera, editable reference circuit, environment, HUD, tests and docs. |
| **v0.2.0 — Race Foundations** | Current work: single-player time trial, READY/countdown/racing/results, ordered directional checkpoints, three laps, timing, checkpoint-based recovery, restart, reference environment refinement. Developer review pending. |
| **v0.3.0 — Arcade Handling** | Tune feel from playtests, introduce drifting/boost deliberately, improve surface response and feedback. |
| **v0.4.0 — Racing Competitors** | Competitor driving, path following, overtaking and difficulty. |
| **v0.5.0 — Power-Up Mayhem** | Original power-ups, pickups, interactions, readable effects and balance. |
| **v0.6.0 — Playable Alpha** | Cohesive race loop, menus, sound, original circuits and broader device testing. |
| **v0.7.0 — Game Identity** | Original characters, karts, visual identity, original environments and audio. Replace the educational reference circuit for distribution. |
| **v0.8.0 — Multiplayer Foundations** | Networking approach, synchronization and multiplayer prototype. |
| **v0.9.0 — Beta & Balancing** | Performance, stability, accessibility, content polish and competitive balance. |
| **v1.0.0 — First Release** | Release-ready original content, tested builds, onboarding and packaging. |

Next review priorities are a complete human-driven three-lap run, keyboard/gamepad input, recovery near the finish, and target hardware. Keep persistent records, advanced menus, kart selection, AI, power-ups, weapons, drifting, multiplayer and online services outside the current patch. Detailed changes belong in CHANGELOG.md; version conventions belong in VERSIONING.md. Change this roadmap only when scope or priorities change.
