# Official Turbo Riot mark

`turbo_riot_logo.png` is a byte-identical runtime copy of the sole supplied primary artwork, `references/brand/logo_overhead.png`. The original reference remains unchanged. Resolution: 1920 × 819, RGBA with transparency.

SHA-256: `2e248ca86eb58fc27596fd556199e1ef78bad1f04254f679195bf97997a584fe`.

The Circuit 8 gantry uses this texture on both faces, unlit and white-modulated, with unchanged UVs/aspect ratio. Its 3.84 × 1.638 m display fits inside the existing 22 × 1.8 m panel. The deliberately narrow artwork footprint follows the supplied logo's proportions; stretching it across the beam would distort it. No fonts or additional circuit wording form part of the branding.

Runtime import settings enable mipmaps for stable distance filtering; the source PNG bytes and alpha are unchanged.
