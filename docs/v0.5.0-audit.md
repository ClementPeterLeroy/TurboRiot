# v0.5.0 pre-implementation audit

Audit and implementation date: 2026-11-10. Target: **0.5.0-dev**, Unreleased pending developer acceptance.

Before changes, the existing project metadata read 0.4.0-dev / Windows 0.4.0.0 and its complete regression suite passed **568 checks, zero failures**. Inspected main/kart/input/controller/config, surfaces, drift/boost, procedural track/features/colliders, race sessions/field manager/recovery, cached AI pursuit/traffic, camera/render interpolation, visuals/HUD and roadmap/changelog/version/acceptance documents. Baseline SHA-256 hashes and copies of current documentation were saved locally under ignored `.godot/v05_baseline/` before source edits.

Read-only Git inspection found the v0.3.2 commit `96934a4`, earlier handling/corrective history and no local tags. Later read-only inspection in this session found developer-managed commit `0d69490` titled v0.4.0 — Racing Competitors. This does not establish a release or manual acceptance. No Git mutation is performed; the original v0.4 Unreleased changelog entry and all earlier development/release records are preserved. The saved main-scene difficulty **2 / Challenging**, UIDs and other user-authored scene settings remain.

Two concrete pre-existing behaviours require the requested corrections. Near-vertical kart contacts entered the static-wall response and multiplied retained speed by 0.45, causing unjustified losses of forward momentum. Pads had a one-second continuous world-direction acceleration/yaw branch that bypassed ordinary steering/pedals. These are replaced with shared pair impulses and a one-entry pad impulse, respectively. Ground snapping, legitimate ramp launch handling, camera and visual presentation scripts are not changed.

The repository uses `DrivingCommand`, rather than the brief's generic KartCommand name. It is extended compatibly with an optional use-item boolean. Existing Space starts READY only; it now also activates a held item during racing with a release/press latch. Gamepad B was unused and becomes item activation. Existing accelerate/brake/steer/drift/start/restart/recovery/debug mappings remain.
