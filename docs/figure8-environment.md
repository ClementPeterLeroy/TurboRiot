# Circuit 8 — editable environment assembly

2026-11-14. Implemented within **v0.6.1-dev**, Unreleased pending developer/artistic acceptance. Version/export metadata is unchanged. This is the first assembled Circuit 8 testing environment, not distribution-ready original circuit content.

## Audit and preserved systems

The 663.556 m, 15 m-wide lap remains generated by TrackBuilder from the saved 36-point Curve3D in `scenes/tracks/figure_8.tscn`; sampling stays at 1 m with a 0.15 m curve bake. `resources/tracks/figure_8_trace.json` remains the original tracing input. The raised diagonal reaches Y=7.04 m; the physical crossing is near (−50.41,6.41,−1.26), above the lower straight at Y=0.04 m.

The curve/elevation data and road configuration are unchanged. TrackBuilder, road/shoulder/collision generation, colored barriers, kart hull/controller, gravity/contact/jump rules, chase camera, checkpoint progression and AI pursuit are preserved. Existing physical barriers still guard the bridge; the gold parapets sit outside them. No new driving floor overlays the asphalt. The existing grass support plane remains, with four modest grass approach wedges added outside the barrier corridor.

The only shared runtime code change is in TrackDefinition: retain authored children of the circuit source scene while transferring the existing Ground and procedural parameters; skip transient `Generated`. Previously only Ground survived and other source children were freed. This dependency is necessary for authored scenery to appear in Quick Race/Time Trial. Existing reference and Yoshi environments are unchanged.

## New editable assets and placement

| Component | Implementation |
| --- | --- |
| Bridge | Separate Blender-authored concrete deck shell, gold parapets and faceted gold panels following the existing raised road. Deck is 0.7 m thick and below the driving surface; 42 native box sections provide structural collision. |
| Supports | Four individually editable concrete piers with simple box collisions. Their footprints clear the lower road/barriers; no support occupies the crossing lane. |
| Grandstands | Two instances of one original 60 m-wide, six-tier stand with shared seating bands, steel frame, teal canopy and editable Turbo Riot banner. Each uses one simple structural collision mass. |
| Placement | Finish stand centered near (18,−0.08,22), facing the start straight; north stand near (52,−0.08,−112), facing the outer north loop. Both remain outside playable road space. |
| Terrain | Four Blender-authored approach verge strips, with upward-facing collision and grass SurfaceConfig. The central underpass stays open. No arbitrary landscape/sculpting or terrain tiles. |
| Small props | Four individually editable shared flag scenes. No spectators, foliage particles, transparent vegetation or imported advertising artwork. |

Privately inspected references were `references/tracks/Figure 8/bridge_reference.png`, `stands_reference.png` and `figure_8_overhead_map.png`. Their gold bridge treatment, canopy/stepped-seating language and outer-loop/finish-straight stand zones informed this assembly. The reference has a much larger, partly curved stadium; two straight modules are a conservative approximation that preserves the playable layout. No reference bitmaps, logos or textures are runtime assets.

## Files and artist workflow

```text
scenes/tracks/figure_8.tscn
  EnvironmentArt (PackedScene)
    Bridge / Shell, DeckCollision, Supports
    Terrain / ApproachVerges, VergeCollision
    Grandstands / FinishStand, NorthStand
    Props / RaceFlag0…3

scenes/environment/figure8/figure8_environment.tscn
scenes/environment/figure8/grandstand.tscn
scenes/environment/figure8/race_flag.tscn
assets/environment/figure8/{bridge_shell,approach_verges,grandstand}.glb
assets/environment/figure8/sources/{bridge_shell,approach_verges,grandstand}.blend
```

Open `figure8_environment.tscn` to select, move, hide or replace entire stands/flags and inspect independent bridge collision helpers. Edit the shared `grandstand.tscn` for its banner and structural collision; editing one placed instance's transform does not move the other. Edit the `.blend` source for canopy/seating/shell geometry, then re-export over its corresponding GLB. Model geometry is separate from native collision helpers; revalidate collision whenever a model changes. Do not merge the environment with the road or put authored objects under transient `Generated`.

The `sources/.gdignore` prevents duplicate Blender import/export dependencies while retaining editable source files for the owner. Shared GLB instances reuse meshes/materials; flags share native mesh resources. Materials are simple opaque PBR, with Blender backface culling enabled and explicit color conversion for matching the Godot palette. Only large structures cast ordinary shadows; flags do not. There are no textures, expensive shaders or animation scripts added.

`resources/tracks/figure_8_environment_profile.json` is a frozen authoring survey of the unmodified road, used to align the bridge/verges. The game does not rebuild scenery from it. Two explicit authoring helpers created the initial assets/scenes:

```powershell
& $blender --factory-startup --disable-autoexec --background --python tools/build_figure8_environment.py
python tools/assemble_figure8_environment.py
```

They refuse to overwrite existing authored outputs by default. `--replace-generated` deliberately discards edits when rebuilding (for Blender, pass it after a separate `--`). Prefer editing the saved Blender/Godot scenes; these helpers are not part of loading, reimport or gameplay. Their coordinates/survey must be updated deliberately if the road changes. No owner-authored Bikini Bottom/Baby Park files were edited.

Run F5 → Quick Race or Time Trial → Choose Circuit → Figure-8. This uses the existing shared race host and gameplay systems; the standalone procedural track remains the authoring scene.

## Native performance

The pre-change track scene was preserved locally before edits. `tests/benchmark_figure8_environment.gd` then loads that snapshot and the completed scene in **one process**, at **1920 × 1080**, Compatibility, VSync off/uncapped, seven AI, Challenging, items seed 42, 60 Hz physics. Each case warms up for 360 ticks then measures 720 ticks. No fixed-FPS mode or concurrent benchmark workload was used. Hardware: AMD Ryzen 7 6800H and **NVIDIA GeForce RTX 3070 Ti Laptop GPU**.

| Metric | Before | After |
| --- | ---: | ---: |
| Average FPS | 170.4 | 164.5 |
| Mean rendered frame | 5.87 ms | 6.08 ms |
| 95th / 99th percentile frame | 11.29 / 12.63 ms | 11.54 / 12.63 ms |
| Mean physics processing | 7.68 ms | 8.42 ms |
| Measured render CPU / GPU | 2.01 / 0.75 ms | 2.06 / 0.77 ms |
| Draw calls | 1,185 | 1,205 |
| Rendered objects | 1,614 | 1,635 |
| Rendered primitives | 236,797 | 244,045 |
| CollisionShape3D nodes | 1,142 | 1,194 |
| Scene nodes | 2,915 | 3,022 |
| Process static memory | 80.55 MB | 81.96 MB |
| Reported video memory | 39.53 MB | 40.40 MB |
| Observed load time | 322.5 ms | 184.2 ms |

The scene adds 52 shapes: 42 deck boxes, four pier boxes, two stand boxes and four small static verge meshes. It adds about 20 draw calls and reduces average FPS by roughly 3.5% in this sample. Both cases keep their 99th-percentile frame below the 16.67 ms budget, supporting the 60 FPS target **in this measured run**. Average FPS exceeds 120, but percentile timing does not establish a sustained 120 FPS experience. Twelve-second measurements are not a whole-lap minimum-FPS guarantee. Load times are cache/order affected, not evidence of a loading optimization. Memory figures are process-level/cache-influenced snapshots, not isolated per-asset budgets.

Reports: [same-process comparison](../artifacts/v061_figure8_environment_comparison.json), [initial pre-change measurement](../artifacts/v061_figure8_environment_baseline.json). The initial isolated baseline measured 175.8 FPS; use the controlled 170.4 → 164.5 comparison above for before/after conclusions. To repeat, provide the preserved pre-change scene via `--baseline-scene=...`; that local snapshot is ignored under `.godot/` and must be retained or reconstructed separately.
