# Turbo Riot roadmap

The canonical roadmap is [ROADMAP.md](../ROADMAP.md). It preserves all ten agreed milestones, records the developer-accepted v0.2.0 baseline and marks **v0.3.0-dev — Arcade Handling** as the current milestone, followed by **v0.3.1 — Corrective Patch** within that scope. Both are unreleased and pending developer acceptance; later milestones are preserved. The original barrier/runoff prerequisite preceded off-road physics; v0.3.1 contains the subsequent reference, checkpoint, directional pad and trunk corrections. See [versioning](../VERSIONING.md) for the unchanged runtime build identity. See [acceptance](acceptance.md) for the cumulative regression policy.
